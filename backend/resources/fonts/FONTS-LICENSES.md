# Bundled fonts

All bundled fonts permit embedding in PDF documents.

| Family | Files | License |
|---|---|---|
| DejaVu Sans | DejaVuSans*.ttf | Bitstream Vera / DejaVu free license (see LICENSE-DejaVu.txt) |
| Liberation Sans | LiberationSans-*.ttf | SIL Open Font License 1.1 |
| Roboto | Roboto-*.ttf | Apache License 2.0 / SIL OFL 1.1 |
| Open Sans | OpenSans-*.ttf | Apache License 2.0 |

Arial is a commercial font and is **not** bundled. On Windows the application uses the
system copy (`C:\Windows\Fonts\arial*.ttf`); where it is missing, the metric-compatible
Liberation Sans is used and the substitution is reported in the validation results.
